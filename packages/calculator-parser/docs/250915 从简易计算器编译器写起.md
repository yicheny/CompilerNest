# v1 简易计算器
目标：
1. 实现数字基本的加减乘除、支持括号

思路：
1. 分词
2. AST生成
3. 解释器

分词和解释器实现很简单，这里重点说一下AST生成的过程。

假设原始输入是：`2 + 3 * (4 - 1)`

分词之后我们得到 `['2', '+', '3', '*', '(', '4', '-', '1', ')']`

执行过程（递归下降），结构变化类似这样：

```
[2]

[+,2]

[+,2,3]

[+,2,[*,3]]

[+,2,[*,3,[]]] //这里是（ 出现的地方

[+,2,[*,3,[4]]]

[+,2,[*,3,[-,4]]]

[+,2,[*,3,[-,4,1]]]

[+,2,[*,3,[-,4,1]]] // 这里是 ）回收的地方
```

这里我用了个简易的结构表示分析的变化，我们可以将这个结构转化为AST结构，本质是不变的，这个结构我认为可以更加形象的表述数据变化的过程：

想象下这个过程如何计算，我们只需要从最底层的叶子节点递归向上回收即可，回收到顶部就可以得到最终结果。

对应的AST如下：

```json5
{
  type: 'BinaryExpr',
  operator: '+',
  left: { type: 'NumberLiteral', value: 2 },
  right: {
    type: 'BinaryExpr',
    operator: '*',
    left: { type: 'NumberLiteral', value: 3 },
    right: {
      type: 'BinaryExpr',
      operator: '-',
      left: { type: 'NumberLiteral', value: 4 },
      right: { type: 'NumberLiteral', value: 1 }
    }
  }
}
```
